# nekoris
液体のような感触のネコたちの落ちものゲームをGodotで開発します。

## 開発

### テスト
GUT をヘッドレスで実行します。Godot の場所は環境変数 `GODOT` で指定します。

```sh
GODOT=/path/to/Godot_console.exe ./run_tests.sh
```

### 動作確認・調整用ツール（`tools/`）
どれも `godot --headless --fixed-fps 120 -s tools/<名前>.gd -- [引数]` で実行します。ウィンドウは開きません。

| ツール | 内容 |
|---|---|
| `inspect.gd` | デモに猫を落として、スコア・今と次の猫・各猫の状態と、容器の中の配置を文字の図で出力する。例: `-- drops=300,240,360 frames=900 every=300` |
| `drop_test.gd` | 段階ごとに猫を床へ落とし、着地の質感（落下速度・顔の沈み込み・跳ね返り・潰れ・揺れが収まるまでの時間）を数値で出す。`名前=値` でパラメータを上書きして比べられる。例: `-- gravity=2000 damp=3 internal_damping=60` |
| `soak.gd` | 猫を40匹積み、面積比・容器からの飛び出し・猫どうしの食い込みを計測する |
| `rest_test.gd` | 床に置いた猫が静止したときの面積比を段階ごとに測る |
| `screenshot.gd` | 画面を PNG に保存する。見た目そのものを確かめたいときだけ使う（`--headless` なしで実行し、ウィンドウが開く） |

## 質感の調整パラメータ

猫の手触りを決める値の一覧です。猫はコードで生成しているので、エディタのインスペクタではなく各ファイルの値を書き換えて調整します。
値を変えたら `tools/drop_test.gd` で数値を比べ、デモで触って確かめるのがおすすめです。`drop_test.gd` では、下の表で **★** の付いた値をファイルを書き換えずに `名前=値` で試せます。

`tests/integration/test_landing_feel.gd` は、今の質感（ふわっと落ちて跳ねない）が崩れていないかを見張るテストです。質感を意図して変えたときは、このテストの目標値も見直してください。

### 重力と空気抵抗（`project.godot` の `[physics]`）
| 設定 | 値 | 効果 |
|---|---|---|
| `2d/default_gravity` ★`gravity` | 1600 | 重力。大きいほど早く最高速度に達し、積まれたときの潰れも大きくなる |
| `2d/default_linear_damp` ★`damp` | 2.5 | 空気抵抗。落下の最高速度はおよそ 重力 ÷ 空気抵抗（今は約 640 px/s）。大きいほど水の中のようにゆっくり落ちる |
| `common/physics_ticks_per_second` | 120 | 1秒あたりの物理計算の回数。下げると固い値（ばねの強さなど）で揺れが暴れやすくなる |

落下の最高速度を変えずに、落ち始めからのテンポだけを変えたいときは、重力と空気抵抗を同じ比率で変えます（例: 2000 / 3.0）。

### 猫の体（`src/blob/blob.gd`）
猫は、外周に並べた小さな玉の輪と、中心にある見えない重りでできています。顔と数字は重りの位置に描きます。

| 変数 | 値 | 効果 |
|---|---|---|
| `pressure_strength` ★ | 120 | 減った面積を元に戻そうと膨らむ力。大きいほど張りが出て潰れにくい |
| `pressure_max` ★ | 30000 | 膨らむ力の玉1個あたりの上限。大きいほど強く押されたときの反発が増える |
| `skin_stiffness` ★ | 2000 | 玉の間隔が伸びたときに引き戻す皮の強さ（縮むときは働かない）。大きいほど伸びにくく丸い |
| `skin_damping` ★ | 8 | 皮が伸びるときのブレーキ |
| `internal_damping` ★ | 40 | 体の変形の揺れを吸収する粘り。大きいほど着地でぽよんと跳ねず、すぐ落ち着く。上げすぎると粘土のように鈍くなる |
| `core_stiffness` ★ | 1500 | 中心の重りを輪の中心へ引き戻すばね。小さいと着地で顔が沈み込み、体からはみ出す |
| `core_damping` ★ | 78 | 重りの揺れのブレーキ。2√(core_stiffness) 付近（今は約 77）で揺れ戻しなしで止まる |
| `area_per_mass` ★ | 300 | 質量の決め方（面積 ÷ この値）。大きいほど軽い。小さい猫は玉の質量が大半なので効きにくい |
| `bead_mass` ★ | 1 | 外周の玉1個の質量 |
| `bead_radius` ★ / `bead_spacing` ★ | 10 / 14 | 外周の玉の大きさと間隔。間隔を広げると玉が減って形が粗くなるが軽くなる |
| `grow_time` | 0.25 | 合体した猫が小さい状態から元の大きさまで膨らむ秒数 |

玉の摩擦と反発（`_ready` 内の `friction` / `bounce`）はどちらも 0 です。

### 猫の大きさと出現（`src/rules/cat_rules.gd`）
| 定数 | 値 | 効果 |
|---|---|---|
| `BASE_RADIUS` | 24 | いちばん小さい猫（2）の半径 |
| `GROWTH` | 1.12 | 段階が1つ上がるごとの半径の倍率 |
| `MAX_SPAWN_TIER` | 3 | 落とす猫の最大の段階（3 = 数字 16 まで） |

### 合体（`src/game/cat_field.gd`）
| 定数 | 値 | 効果 |
|---|---|---|
| `MERGE_DELAY` | 0.5 | 同じ段階の猫がこの秒数だけ触れ続けたら合体する。途中で離れたら数え直す |
| `CONTACT_MARGIN` | 2 | 玉どうしがこの距離 (px) だけ離れていても触れているとみなす余裕 |
| `MERGE_START_SCALE` | 0.5 | 合体した猫を出すときの大きさの倍率（ここから `grow_time` かけて膨らむ） |

### 操作と容器（`src/game/demo.gd`）
| 定数・設定 | 値 | 効果 |
|---|---|---|
| `DROP_COOLDOWN` | 0.5 | 猫を落としてから次の猫を構えるまでの秒数 |
| `DROP_Y` | 容器の上端 − 60 | 構えた猫を落とす高さ |
| `CONTAINER` | (100, 200, 400×650) | 容器の位置と大きさ |
| 壁の `friction` | 0.1 | 容器の壁と床の摩擦 |
